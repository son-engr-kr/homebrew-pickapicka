# homebrew-pickapicka

Homebrew tap for [Pickapicka](https://github.com/son-engr-kr/pickapicka).

## Install

```bash
brew tap son-engr-kr/pickapicka
brew install pickapicka
pickapicka serve
```

## Upgrade

```bash
brew update
brew upgrade pickapicka
```

## From Picture Classifier

The app and this tap were called picture-classifier up to 0.9.0:

```bash
brew uninstall picture-classifier
brew untap son-engr-kr/picture-classifier
brew tap son-engr-kr/pickapicka
brew install pickapicka
```
